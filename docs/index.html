슬림 비디오는 휴대폰 안의 동영상 용량을 줄여 주는 안드로이드 앱입니다. 휴대폰의 하드웨어 인코더를 그대로 써서 서버 없이 앱 안에서만 변환하고, 원본 영상은 건드리지 않습니다.

주요 기능

화질 유지 압축

해상도는 그대로 두고 H.265 고효율로 다시 인코딩합니다. 1080p H.264 원본이면 보통 40~65% 줄어듭니다.

공유용 · 초경량

카톡·SNS 전송에 맞춘 1080p 균형 모드와, 짧은 변 480p까지 줄이는 초경량 모드.

목표 용량 맞추기

10·25·50·100MB 중 목표를 고르면 길이로 비트레이트를 계산해 맞춥니다. 너무 작으면 해상도를 자동으로 낮춥니다.

H.265 / H.264

최소 용량(H.265)과 호환성(H.264) 중에서 고릅니다. 기기에 H.265 인코더가 없으면 자동으로 H.264로 저장하고 알려 줍니다.

앱을 내려도 계속

압축 중 화면을 나가거나 화면이 꺼져도 진행률 알림과 함께 끝까지 변환합니다.
